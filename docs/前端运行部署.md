# 语义层前端运行与部署

前端位于 `frontend/`，技术栈为 Vue 3 + Vite + TypeScript + Element Plus + Pinia + Vue Router + Vue I18n。

## 一、环境要求

- Node.js >= 18
- npm >= 9

## 二、安装与启动

```bash
cd frontend
npm install
npm run dev
```

默认访问 http://localhost:5173 。

开发环境通过 Vite 代理把 `/api`、`/health` 转发到后端（默认 `http://127.0.0.1:8888`）：

```ini
# frontend/.env.development
VITE_API_BASE_URL=
VITE_PROXY_TARGET=http://127.0.0.1:8888
```

如果后端不在本机，修改 `VITE_PROXY_TARGET` 即可。

## 三、构建与预览

```bash
npm run build      # 产物在 frontend/dist
npm run preview    # 本地预览构建产物
npm run typecheck  # vue-tsc 类型检查
```

生产部署时把 `dist/` 交给 Nginx，并将 `/api`、`/health` 反向代理到语义层后端。

## 四、目录结构

```text
frontend/
├── src/
│   ├── api/

│   ├── i18n/               # 中英文词条

│   ├── router/             # 路由表

│   ├── styles/             # 全局样式与公共页面类
│   ├── views/              # 8 个业务页面
│   │   ├── workbench/
│   │   ├── domains/
│   │   ├── models/
│   │   ├── metrics/
│   │   ├── bindings/
│   │   ├── knowledge/
│   │   ├── release/
│   │   ├── admin/
│   │   └── components/     # 页面公共组件
│   ├── App.vue
│   └── main.ts

├── vite.config.ts

```

## 五、页面与路由

| 页面 | 路由 |
| --- | --- |
| 工作台 | `/workbench` |
| 主题域 | `/domains` |
| 语义模型 | `/models` |
| 新建模型 | `/models/create` |
| 模型详情 | `/models/:id` |
| 指标管理 | `/metrics` |
| 数据绑定 | `/bindings` |
| 新建绑定 | `/bindings/create` |
| 字段映射 | `/bindings/:id/mapping` |
| 知识上下文 | `/knowledge` |
| 校验与发布 | `/release` |
| 系统管理 | `/admin` |

## 六、开发约定

- 请求统一走 `src/api/semantic.ts`，不要在页面里直接使用 axios。
- 后端统一响应 `{code, message, data, request_id}`，`client.ts` 已做解包与错误归一。
- 用户与角色开发期通过 `localStorage` 的 `semantic-layer.user`、`semantic-layer.roles` 覆盖，默认 `dev-user` / `admin,modeler`。
- 页面文案双语放在 `src/i18n/locales/`。
